# CS2 Style 3D Prototype

Bu proje, HTML + JavaScript + Three.js kullanarak çalışan CS2 hissi veren bir 3D FPS prototipidir.

## Özellikler

- Ana menü
- W/A/S/D hareket
- Shift sprint
- Ctrl eğilme
- Space bhop jump
- A / B site bölgeleri
- Bomb planting sistemi
- Round timer
- 3D harita ve objeler
- Bot baskısı
- HUD, silah ve can bilgisi

## Çalıştırma

1. Projeyi bilgisayarınıza indirin.
2. Klasörün içindeyken terminal açın.
3. Aşağıdaki komutu çalıştırın:

```bash
python -m http.server 8000
```

4. Tarayıcıda açın:

```text
http://localhost:8000
```

## Kontroller

- W/A/S/D = Hareket
- Shift = Sprint
- Ctrl = Crouch / Eğilme
- Space = Bhop Jump
- E = Bomb Plant
- Sol tık = Ateş
- Fare = Kamerayı döndür

## Not

Bu bir prototiptir; tam CS2 klonuna dönüşmesi için daha sonra eklenmesi gerekenler:

- çoklu oyuncu
- daha fazla silah ve recoil
- buy menu
- smoke / flash / molotov
- daha gelişmiş botlar
- gerçekçi haritalar
- ses efektleri
- scoreboard ve matchmaking
